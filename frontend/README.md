# Her Day — Frontend Prototype

A frontend-only React/Vite prototype using the approved Tidal Glass design.

## Pages

- `/` — Login and persona selection
- `/elder` — Fatima's daily check-in
- `/coordinator` — Yusuf's care coordination view
- `/caregiver` — Amina's caregiver briefing
- `/caregiver?who=lea` — Léa's agency-caregiver briefing
- `/family` — Mona's family view

All demo data, consent changes, recordings, schedule changes, and reset behavior
remain in the browser. There are no backend or API calls.

## Run

```sh
pnpm install
pnpm dev
```
